# PhysioCare - صفحة حجز مواعيد للعلاج الطبيعي

هذا المشروع هو واجهة بسيطة لمركز علاج طبيعي يُدعى "PhysioCare"، يتكون من صفحة رئيسية تعريفية وصفحة لحجز المواعيد.

## ✨ الميزات

-   **تصميم حديث:** واجهة نظيفة وجذابة باستخدام ألوان متدرجة.
-   **متجاوب مع الأجهزة:** تصميم يعمل بشكل جيد على شاشات الحاسوب والهواتف.
-   **صفحة حجز:** نموذج متكامل لحجز المواعيد مع حقول لبيانات المريض وتفاصيل الحجز.

## 🛠️ التقنيات المستخدمة

-   **HTML5:** لهيكلة المحتوى.
-   **CSS3:** للتصميم والتحريك.
-   **Tailwind CSS:** إطار عمل CSS لتسريع عملية التصميم.
-   **Google Fonts:** لاستخدام خط "Cairo" للغة العربية.

## 🚀 كيفية تشغيل المشروع محلياً

1.  قم بتحميل المشروع أو استنساخه من المستودع:
    ```bash
    git clone [https://github.com/eyad7330/PhysioCare.git](https://github.com/eyad7330/PhysioCare.git)
    ```
2.  انتقل إلى مجلد المشروع:
    ```bash
    cd PhysioCare
    ```
3.  افتح ملف `index.html` في متصفحك مباشرة.
